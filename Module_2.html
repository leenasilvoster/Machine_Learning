Gradient descent algorithm

Gradient descent algorithm

Gradient descent is the most common optimization algorithm in machine learning and deep learning. It is a first-order optimization algorithm, which means it only takes into account the first derivative when performing the updates on the parameters.

On each iteration, we update the parameters in the opposite direction of the gradient of the objective function \(J(w)\) with respect to the parameters, because the gradient gives the direction of the steepest ascent. The size of the step we take on each iteration to reach the local minimum is determined by the learning rate \(\alpha\). Therefore, we follow the direction of the slope downhill until we reach a local minimum.

$$w:=w-\alpha\,\nabla_wJ(w)$$
📌 Why the minus sign?
On the left of the minimum the gradient is negative, so \(-\alpha\nabla_wJ\) is positive and \(w\) increases (moves right, towards the minimum). On the right the gradient is positive, so \(w\) decreases. At the minimum \(\nabla_wJ=0\), so \(w\) stops changing.

Linear regression solution using gradient descent

The cost function (objective function) to be minimized is the Mean Square Error (MSE) in approximating the data:

$$J(\boldsymbol\theta)=\frac{1}{2n}\sum_{i=1}^{n}\left(h_{\boldsymbol\theta}\big(\boldsymbol{x}^{(i)}\big)-y^{(i)}\right)^2,\qquad h_{\boldsymbol\theta}(\boldsymbol{x})=\sum_{k=0}^{d}\theta_kx_k\ \ (x_0=1)$$
  • Initialize \(\boldsymbol\theta\).
  • Repeat until convergence: \(\displaystyle\theta_j\leftarrow\theta_j-\alpha\frac{\partial}{\partial\theta_j}J(\boldsymbol\theta)\), a simultaneous update for \(j=0,\dots,d\).

The partial derivative

$$\begin{aligned}\frac{\partial}{\partial\theta_j}J(\boldsymbol\theta)&=\frac{\partial}{\partial\theta_j}\frac{1}{2n}\sum_{i=1}^{n}\left(h_{\boldsymbol\theta}\big(\boldsymbol{x}^{(i)}\big)-y^{(i)}\right)^2\\&=\frac{\partial}{\partial\theta_j}\frac{1}{2n}\sum_{i=1}^{n}\left(\sum_{k=0}^{d}\theta_kx_k^{(i)}-y^{(i)}\right)^2\\&=\frac1n\sum_{i=1}^{n}\left(\sum_{k=0}^{d}\theta_kx_k^{(i)}-y^{(i)}\right)\times\frac{\partial}{\partial\theta_j}\left(\sum_{k=0}^{d}\theta_kx_k^{(i)}-y^{(i)}\right)\\&=\frac1n\sum_{i=1}^{n}\left(\sum_{k=0}^{d}\theta_kx_k^{(i)}-y^{(i)}\right)x_j^{(i)}\end{aligned}$$

Only the term with \(k=j\) depends on \(\theta_j\), so the last derivative is simply \(x_j^{(i)}\). Substituting gives the final update rule:

$$\boxed{\theta_j\leftarrow\theta_j-\alpha\,\frac1n\sum_{i=1}^{n}\left(h_{\boldsymbol\theta}\big(\boldsymbol{x}^{(i)}\big)-y^{(i)}\right)x_j^{(i)}}\qquad\text{simultaneous update for }j=0,\dots,d$$

Choosing the learning rate \(\alpha\)

\(\alpha\) too smallA small learning rate requires many updates before reaching the minimum point (slow convergence).
\(\alpha\) too largeDrastic updates may overshoot the minimum, may fail to converge, and may even diverge, with \(J(\boldsymbol\theta)\) increasing.

Stochastic gradient descent

On-line gradient descent, also known as sequential gradient descent or stochastic gradient descent, makes an update to the weight vector based on one data point at a time. Instead of summing the error over all \(n\) points before each step, it updates after each single point \(i\):

$$\theta_j\leftarrow\theta_j-\alpha\left(h_{\boldsymbol\theta}\big(\boldsymbol{x}^{(i)}\big)-y^{(i)}\right)x_j^{(i)}$$

Matrix method

Solution using the matrix method

Gradient descent reaches the best parameters step by step. The matrix method finds them directly in one calculation, by setting the gradient of the cost function to zero and solving for \(\boldsymbol\theta\).

Setting up the matrices

Let there be \(n\) training examples and \(d\) features. Put a constant \(x_0=1\) in front of every example so that the intercept \(\theta_0\) is handled like any other parameter.

$$X=\begin{bmatrix}1&x_1^{(1)}&\cdots&x_d^{(1)}\\1&x_1^{(2)}&\cdots&x_d^{(2)}\\\vdots&\vdots&&\vdots\\1&x_1^{(n)}&\cdots&x_d^{(n)}\end{bmatrix},\qquad\mathbf{y}=\begin{bmatrix}y^{(1)}\\y^{(2)}\\\vdots\\y^{(n)}\end{bmatrix},\qquad\boldsymbol\theta=\begin{bmatrix}\theta_0\\\theta_1\\\vdots\\\theta_d\end{bmatrix}$$

\(X\) is the \(n\times(d+1)\) design matrix. The predictions for all examples are given at once by \(\hat{\mathbf{y}}=X\boldsymbol\theta\), and the cost function becomes

$$J(\boldsymbol\theta)=\frac{1}{2n}(X\boldsymbol\theta-\mathbf{y})^T(X\boldsymbol\theta-\mathbf{y})$$

Deriving the solution

The gradient of \(J\) with respect to \(\boldsymbol\theta\) is

$$\nabla_{\boldsymbol\theta}J=\frac1nX^T(X\boldsymbol\theta-\mathbf{y})$$

This is the matrix form of the sum \(\frac1n\sum_i(h_{\boldsymbol\theta}(\boldsymbol{x}^{(i)})-y^{(i)})x_j^{(i)}\) from the gradient descent update. At the minimum the gradient is zero:

$$X^T(X\boldsymbol\theta-\mathbf{y})=0\;\Rightarrow\;X^TX\,\boldsymbol\theta=X^T\mathbf{y}$$

If \(X^TX\) is invertible, multiplying both sides by \((X^TX)^{-1}\) gives the normal equation:

$$\boxed{\boldsymbol\theta=(X^TX)^{-1}X^T\mathbf{y}}$$

Worked example

Fit a line \(y=\theta_0+\theta_1x\) to the points \((1,1)\), \((2,2)\) and \((3,2)\).

$$X=\begin{bmatrix}1&1\\1&2\\1&3\end{bmatrix},\qquad\mathbf{y}=\begin{bmatrix}1\\2\\2\end{bmatrix}$$
$$X^TX=\begin{bmatrix}3&6\\6&14\end{bmatrix},\qquad X^T\mathbf{y}=\begin{bmatrix}1+2+2\\1+4+6\end{bmatrix}=\begin{bmatrix}5\\11\end{bmatrix}$$

The determinant of \(X^TX\) is \(3\cdot14-6\cdot6=6\), so

$$(X^TX)^{-1}=\frac16\begin{bmatrix}14&-6\\-6&3\end{bmatrix},\qquad\boldsymbol\theta=\frac16\begin{bmatrix}14\cdot5-6\cdot11\\-6\cdot5+3\cdot11\end{bmatrix}=\frac16\begin{bmatrix}4\\3\end{bmatrix}=\begin{bmatrix}2/3\\1/2\end{bmatrix}$$

The fitted line is \(\boxed{\hat{y}=\tfrac23+\tfrac12x}\).

✅ Check
The predictions are \(\tfrac76,\ \tfrac53,\ \tfrac{13}{6}\), so the errors \(\hat{y}-y\) are \(\tfrac16,\ -\tfrac13,\ \tfrac16\). They add up to zero, and so do the errors multiplied by \(x\): \(\tfrac16-\tfrac23+\tfrac12=0\). This is exactly the condition \(X^T(X\boldsymbol\theta-\mathbf{y})=0\).

The same formula works for several variables. Only the number of columns of \(X\) changes.

Overfitting in regression

Basic idea of overfitting in regression

A good regression model should fit the training data and also predict new, unseen data well. The model can fail in two opposite ways.

UnderfittingOverfittingGood fit
Training errorHighLowMinimum
Testing errorHighHighMinimum
ProblemHigh biasHigh varianceBias–variance trade-off

Quality of fit

Suppose we predict the price of a house from its size \(x\). The same data can be fitted with polynomials of different degree:

ModelFit
\(\theta_0+\theta_1x\)Underfitting (high bias): too simple to follow the curve in the data
\(\theta_0+\theta_1x+\theta_2x^2\)Correct fit
\(\theta_0+\theta_1x+\theta_2x^2+\theta_3x^3+\theta_4x^4\)Overfitting (high variance): passes through every point but wiggles between them

What is bias?

  • Bias is the difference between the average prediction of our model and the correct value which we are trying to predict.
  • A model with high bias pays very little attention to the training data and oversimplifies the model.
  • It always leads to high error on training and test data.

What is variance?

  • Variance is the variability of the model prediction for a given data point, a value which tells us the spread of our data.
  • A model with high variance pays a lot of attention to the training data and does not generalize to data it has not seen before.
  • Such models perform very well on training data but have high error rates on test data.
Low biasThe average prediction is very close to the target value.
High biasThe predictions differ too much from the actual value.
Low varianceThe predictions are compact and do not vary much from their mean value.
High varianceScattered predictions with huge variations from the mean value and from each other.

Bias–variance trade-off

📌 In short
A model that is too simple has high bias and underfits. A model that is too complex has high variance and overfits. We aim for the complexity where the testing error is smallest.

Overfitting

The learned hypothesis may fit the training set very well, but may fail to generalize to new examples.

How to avoid overfitting

  • Reduce the number of features. An overfitting algorithm captures the noise in the data, so using fewer features helps.
  • K-fold cross validation to estimate how the model performs on unseen data.
  • Increase the training data.
  • Regularization.

Regularization

Regularization adds a penalty on the size of the coefficients to the least-squares (LS) objective. This keeps the coefficients small, makes the model less sensitive to noise, and reduces variance. The constant \(\lambda\ge0\) controls the strength of the penalty. With \(\lambda=0\) we get ordinary least squares.

Lasso regression (L1)Least Absolute Shrinkage and Selection Operator. It adds a penalty equal to the absolute value of the magnitude of the coefficients. It can shrink some coefficients to exactly zero, so it also selects features.
Ridge regression (L2)It adds a penalty equal to the square of the magnitude of the coefficients. It shrinks all coefficients towards zero.

Minimization objective = LS objective \(+\ \lambda\times\)(penalty on the coefficients):

$$\text{Lasso (L1):}\quad\sum_{i=1}^{M}\Big(y_i-\sum_{j=0}^{p}w_jx_{ij}\Big)^2+\lambda\sum_{j=0}^{p}|w_j|$$ $$\text{Ridge (L2):}\quad\sum_{i=1}^{M}\Big(y_i-\sum_{j=0}^{p}w_jx_{ij}\Big)^2+\lambda\sum_{j=0}^{p}w_j^2$$

How to avoid underfitting

Increase the model complexity. For example, if a linear function underfits the data, try using polynomial features.

How to detect overfitting

Do not judge a model only by its error on the data it was trained on. Keep some data aside and compare the two errors:

  • Underfitting: training error and testing error are both high.
  • Overfitting: training error is low but testing error is high. A large gap between them is the warning sign.
  • Good fit: both errors are low and close to each other.

With K-fold cross validation, the data is split into \(K\) equal parts. The model is trained on \(K-1\) parts and tested on the remaining part, this is repeated \(K\) times so that every part is used once for testing, and the \(K\) test errors are averaged.

Logistic regression

Linear methods for classification

In classification the output is a discrete class label, not a number. This part of the module covers three methods: logistic regression, Naive Bayes and the ID3 decision tree algorithm.

Logistic regression

Suppose we want to predict whether a student passes an exam (\(y=1\)) or fails (\(y=0\)) from the hours of study \(x\). A straight line is a poor fit for 0/1 outcomes, but an S-shaped curve that gives the probability of passing fits well.

Logistic (sigmoid) function

$$p=\frac{1}{1+e^{-(\beta_0+\beta_1x)}}$$

The output always lies between 0 and 1, so it can be read as a probability. It equals 0.5 when \(\beta_0+\beta_1x=0\), approaches 0 for large negative values and approaches 1 for large positive values.

Logit

For an observation \(x_i\), the probability can be written in either of two equivalent forms:

$$p_i=\frac{1}{1+e^{-(\beta_0+\beta_1x_i)}}=\frac{e^{\beta_0+\beta_1x_i}}{e^{\beta_0+\beta_1x_i}+1}$$

Log odds

  • Odds (odds of success) is the chance of success divided by the chance of failure: \(\text{Odds}=\dfrac{p}{1-p}\).
  • Log odds is the logarithm of the odds: \(\text{Log odds}=\log\dfrac{p}{1-p}\).

Log odds (logit) function

Let \(z=\beta_0+\beta_1x_1\). Then

$$p=\frac{e^{z}}{1+e^{z}},\qquad1-p=1-\frac{e^{z}}{1+e^{z}}=\frac{1}{1+e^{z}},\qquad\frac{p}{1-p}=e^{z}$$

Taking the logarithm of the odds gives a linear function of \(x_1\):

$$\boxed{\log\!\left(\frac{p}{1-p}\right)=\beta_0+\beta_1x_1}$$
📌 In short
Logistic regression is a linear model for the log odds. A new point is classified as class 1 when \(p\ge0.5\), which happens exactly when \(\beta_0+\beta_1x\ge0\).

Logistic regression model

The statistical model for logistic regression is \(\log\!\left(\dfrac{p}{1-p}\right)=\beta_0+\beta_1x\).

Here \(p\) is a binomial proportion (the probability of success) and \(x\) is the explanatory variable. The parameters of the logistic regression model are \(\beta_0\) and \(\beta_1\). For the \(i\)-th observation,

$$\log\!\left[\frac{p_i}{1-p_i}\right]=\beta_0+\beta_1x_i$$

(The slide writes \(\beta_0\cdot1\); the \(1\) is the constant input \(x_0=1\) that goes with the intercept.) A plot of the logit against \(x\) is a straight line, with the data scattered around it.
