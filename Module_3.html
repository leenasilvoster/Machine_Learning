Polynomial kernel

Worked example: finding the feature mapping of a kernel

Consider an SVM with 2-D input, \(x=(x_1,x_2)\) and \(y=(y_1,y_2)\), and the kernel

$$K(x,y)=(x\cdot y+1)^2-1$$

Show that this kernel implicitly maps the input to a 5-D feature space.

📌 Idea
A kernel is a shortcut for the dot product in feature space. So we must show that \(K(x,y)=\phi(x)^T\phi(y)\) by expanding the kernel and matching its terms with the features.

1. Define the mapping

Start with a point \(x=(x_1,x_2)\). The mapping \(\phi\) uses those two coordinates to create five features:

$$\phi(x)=\begin{bmatrix}x_1^2\\x_2^2\\\sqrt2\,x_1x_2\\\sqrt2\,x_1\\\sqrt2\,x_2\end{bmatrix}$$

For example, if \(x=(1,2)\), then \(\phi(x)=(1,\,4,\,2\sqrt2,\,\sqrt2,\,2\sqrt2)\). The point \(y\) is mapped in the same way, giving \(\phi(y)=(y_1^2,\,y_2^2,\,\sqrt2\,y_1y_2,\,\sqrt2\,y_1,\,\sqrt2\,y_2)\).

2. Expand the kernel

The original dot product is \(x\cdot y=x_1y_1+x_2y_2\). Substituting it into the kernel gives

$$\begin{aligned}K(x,y)&=(x_1y_1+x_2y_2+1)^2-1\\&=(x_1y_1+x_2y_2)^2+2(x_1y_1+x_2y_2)\\&=x_1^2y_1^2+x_2^2y_2^2+2x_1x_2y_1y_2+2x_1y_1+2x_2y_2\end{aligned}$$

The second line uses \((a+1)^2-1=a^2+2a\). The two constant terms cancel.

3. Match the five terms to the five features

A dot product means multiply matching entries and add the products. Each pair of entries in \(\phi(x)\) and \(\phi(y)\) gives one term of the expanded kernel.

Feature from \(x\)Matching feature from \(y\)Product
\(x_1^2\)\(y_1^2\)\(x_1^2y_1^2\)
\(x_2^2\)\(y_2^2\)\(x_2^2y_2^2\)
\(\sqrt2\,x_1x_2\)\(\sqrt2\,y_1y_2\)\(2x_1x_2y_1y_2\)
\(\sqrt2\,x_1\)\(\sqrt2\,y_1\)\(2x_1y_1\)
\(\sqrt2\,x_2\)\(\sqrt2\,y_2\)\(2x_2y_2\)

The \(\sqrt2\) factors are there because each vector contributes one \(\sqrt2\), giving the coefficient 2 when they are multiplied. Adding the five products gives exactly the kernel expansion:

$$\boxed{\phi(x)^T\phi(y)=K(x,y)=(x\cdot y+1)^2-1}\qquad\blacksquare$$
💡 Kernel trick
Whenever the SVM needs the 5-D dot product, it can evaluate \(K(x,y)\) directly from the original 2-D points. It works as if the data lived in 5-D, where it may become linearly separable, but it only does cheap 2-D calculations.
