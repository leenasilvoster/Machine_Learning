Expectation–Maximization (EM)

Introduction

The Expectation–Maximization algorithm estimates model parameters when some variables are hidden or unobserved.

K-means: hard clusteringEach data point belongs to only one cluster.
EM: soft clusteringEach point has a probability of belonging to each cluster.

In clustering, the hidden variable is the cluster membership of each point.

Main steps

  1. Initialization: choose initial parameter values.
  2. Expectation step (E-step): calculate the probabilities of the hidden variables using the current parameters.
  3. Maximization step (M-step): update the parameters using the probabilities calculated in the E-step.
  4. Convergence check: repeat until the parameter values or the likelihood change very little.

Gaussian mixture model

A Gaussian mixture model assumes that the data are generated by a mixture of \(k\) Gaussian distributions. Each cluster \(C_i\) has:

Mean \(\mu_i\)Its centre.
Covariance matrix \(\Sigma_i\)Its spread, shape and orientation.
Mixture weight \(\pi_i=P(C_i)\)Its prior probability. The weights satisfy \(\sum_{i=1}^{k}\pi_i=1\).

For a \(d\)-dimensional observation \(\mathbf{x}\), the Gaussian density is:

$$f_i(\mathbf{x})=\frac{\exp\left[-\tfrac12(\mathbf{x}-\boldsymbol{\mu}_i)^T\boldsymbol{\Sigma}_i^{-1}(\mathbf{x}-\boldsymbol{\mu}_i)\right]}{(2\pi)^{d/2}|\boldsymbol{\Sigma}_i|^{1/2}}$$

The mixture density is:

$$p(\mathbf{x}\mid\theta)=\sum_{i=1}^{k}\pi_i f_i(\mathbf{x})$$

Likelihood

🤔Ask yourself: how well do the model parameters \(\theta\) explain the observed data?

For independent observations in a dataset \(D\), the likelihood is:

$$L(\theta)=\prod_{j=1}^{n}p(\mathbf{x}_j\mid\theta)$$

The log-likelihood is:

$$\ell(\theta)=\sum_{j=1}^{n}\log\left[\sum_{i=1}^{k}\pi_i f_i(\mathbf{x}_j)\right]$$

EM iteratively improves the parameter estimates so that this value increases.

E-step: cluster membership probabilities

Using Bayes’ theorem:

$$r_{ji}=P(C_i\mid\mathbf{x}_j)=\frac{\pi_i f_i(\mathbf{x}_j)}{\sum_{a=1}^{k}\pi_a f_a(\mathbf{x}_j)}$$

Here \(r_{ji}\) is the responsibility of cluster \(i\) for point \(j\). It acts as the point’s weight in that cluster. For each point, \(\sum_{i=1}^{k}r_{ji}=1\).

M-step: update the parameters

The effective number of points in cluster \(i\) is \(N_i=\sum_{j=1}^{n}r_{ji}\).

$$\boldsymbol{\mu}_i^{\text{new}}=\frac{\sum_{j=1}^{n}r_{ji}\mathbf{x}_j}{N_i}$$ $$\boldsymbol{\Sigma}_i^{\text{new}}=\frac{\sum_{j=1}^{n}r_{ji}(\mathbf{x}_j-\boldsymbol{\mu}_i^{\text{new}})(\mathbf{x}_j-\boldsymbol{\mu}_i^{\text{new}})^T}{N_i}$$ $$\pi_i^{\text{new}}=\frac{N_i}{n}$$
📌 In short
The M-step calculates a weighted mean, a weighted covariance and an updated cluster proportion.

EM algorithm for Gaussian clustering

  1. Select the number of clusters.
  2. Initialize the means, covariance matrices and mixture weights. The slides use random means, identity covariance matrices and equal mixture weights.
  3. Calculate the membership probabilities in the E-step.
  4. Update the parameters in the M-step.
  5. Repeat until convergence.
Algorithm 13.3: Expectation-Maximization (EM) Algorithm
EXPECTATION-MAXIMIZATION (\(\mathbf{D},k,\epsilon\)):
1\(t\leftarrow0\)
// Initialization
2Randomly initialize \(\boldsymbol{\mu}_1^t,\dots,\boldsymbol{\mu}_k^t\)
3\(\boldsymbol{\Sigma}_i^t\leftarrow\mathbf{I},\ \forall i=1,\dots,k\)
4\(P^t(C_i)\leftarrow\tfrac{1}{k},\ \forall i=1,\dots,k\)
5repeat
6\(t\leftarrow t+1\)
// Expectation Step
7for \(i=1,\dots,k\) and \(j=1,\dots,n\) do
8\(w_{ij}\leftarrow\dfrac{f(\mathbf{x}_j\mid\boldsymbol{\mu}_i,\boldsymbol{\Sigma}_i)\cdot P(C_i)}{\sum_{a=1}^{k}f(\mathbf{x}_j\mid\boldsymbol{\mu}_a,\boldsymbol{\Sigma}_a)\cdot P(C_a)}\)// posterior probability \(P^t(C_i\mid\mathbf{x}_j)\)
// Maximization Step
9for \(i=1,\dots,k\) do
10\(\boldsymbol{\mu}_i^t\leftarrow\dfrac{\sum_{j=1}^{n}w_{ij}\cdot\mathbf{x}_j}{\sum_{j=1}^{n}w_{ij}}\)// re-estimate mean
11\(\boldsymbol{\Sigma}_i^t\leftarrow\dfrac{\sum_{j=1}^{n}w_{ij}(\mathbf{x}_j-\boldsymbol{\mu}_i)(\mathbf{x}_j-\boldsymbol{\mu}_i)^T}{\sum_{j=1}^{n}w_{ij}}\)// re-estimate covariance matrix
12\(P^t(C_i)\leftarrow\dfrac{\sum_{j=1}^{n}w_{ij}}{n}\)// re-estimate priors
13until \(\sum_{i=1}^{k}\left\|\boldsymbol{\mu}_i^t-\boldsymbol{\mu}_i^{t-1}\right\|^2\le\epsilon\)

Here \(w_{ij}\) is the responsibility \(r_{ji}\) used in the E-step and M-step equations above, with the indices written in the other order. This version stops when the cluster means stop moving.

General EM algorithm: mathematical formulation

The Gaussian case above is one instance of a general scheme. Let \(X\) be the observed data, \(Z\) the hidden variables and \(\theta\) the parameters. EM maximizes the log-likelihood of the observed data:

$$\ell(\theta)=\log p(X\mid\theta)=\log\sum_{Z}p(X,Z\mid\theta)$$

The sum inside the logarithm is hard to maximize directly, so EM works with the expected complete-data log-likelihood instead.

Input: observed data \(X\), model \(p(X,Z\mid\theta)\), tolerance \(\epsilon>0\).

Initialize \(\theta^{(0)}\) and set \(t=0\).

Repeat until convergence:

E-step. Find the posterior of the hidden variables under the current parameters and form the \(Q\) function:

$$p\!\left(Z\mid X,\theta^{(t)}\right)=\frac{p\!\left(X,Z\mid\theta^{(t)}\right)}{\sum_{Z'}p\!\left(X,Z'\mid\theta^{(t)}\right)}$$ $$Q\!\left(\theta\mid\theta^{(t)}\right)=\mathbb{E}_{Z\mid X,\theta^{(t)}}\!\left[\log p(X,Z\mid\theta)\right]=\sum_{Z}p\!\left(Z\mid X,\theta^{(t)}\right)\log p(X,Z\mid\theta)$$

M-step. Choose the parameters that maximize \(Q\):

$$\theta^{(t+1)}=\underset{\theta}{\arg\max}\;Q\!\left(\theta\mid\theta^{(t)}\right)$$

Convergence check. Stop if \(\left|\ell(\theta^{(t+1)})-\ell(\theta^{(t)})\right|<\epsilon\) or \(\left\|\theta^{(t+1)}-\theta^{(t)}\right\|<\epsilon\). Otherwise set \(t\leftarrow t+1\).

Output: \(\hat\theta=\theta^{(t+1)}\).

📌 Key property
Each iteration satisfies \(\ell(\theta^{(t+1)})\ge\ell(\theta^{(t)})\), so the log-likelihood never decreases. The result can still be a local maximum.
🔗 Link to the Gaussian mixture
Let \(z_{ji}=1\) if point \(j\) comes from cluster \(i\), and 0 otherwise. The E-step replaces \(z_{ji}\) by its expected value \(r_{ji}\), giving $$Q=\sum_{j=1}^{n}\sum_{i=1}^{k}r_{ji}\left[\log\pi_i+\log f_i(\mathbf{x}_j)\right]$$ Maximizing this over \(\boldsymbol{\mu}_i\), \(\boldsymbol{\Sigma}_i\) and \(\pi_i\) gives exactly the weighted mean, weighted covariance and \(N_i/n\) updates of the M-step.

Applications

  • Clustering unlabelled data.
  • Parameter estimation with missing observations.
  • Estimating hidden or latent variables.
  • Estimating Hidden Markov Model parameters.

Advantages and limitations

✅ Advantages
  • Supports probabilistic cluster membership.
  • Handles models containing hidden variables.
  • Under exact EM updates, the likelihood does not decrease.
⚠️ Limitations
  • Convergence can be slow.
  • Results depend on initialization.
  • A global optimum is not guaranteed.
💡 Technical note
Forward and backward probabilities are used in the HMM application of EM. They are not required by every EM problem.

When the coin identities are known

If experiments 2, 3 and 5 use coin A, and experiments 1 and 4 use coin B:

$$\theta_A=\frac{9+8+7}{30}=\frac{24}{30}=0.8,\qquad \theta_B=\frac{5+4}{20}=\frac{9}{20}=0.45$$

When the coin identities are hidden

EM estimates the coin biases by repeatedly calculating probable coin identities and updating the biases. Start with \(\theta_A=0.6\) and \(\theta_B=0.5\), and assume both coins are equally likely to be selected.

E-step

For an experiment with \(h\) heads and \(t\) tails, calculate and normalize:

$$L_A=\theta_A^h(1-\theta_A)^t,\quad L_B=\theta_B^h(1-\theta_B)^t,\quad r_A=\frac{L_A}{L_A+L_B},\quad r_B=1-r_A$$

The binomial coefficient is common to both likelihoods, so it cancels during normalization.

📌 Experiment 1: 5 heads, 5 tails
\(L_A=0.6^5\times0.4^5=0.0007962624\) and \(L_B=0.5^{10}=0.0009765625\). So \(r_A\approx0.4491\) and \(r_B\approx0.5509\).
📌 Experiment 2: 9 heads, 1 tail
\(L_A=0.6^9\times0.4=0.0040310784\) and \(L_B=0.5^{10}=0.0009765625\). So \(r_A\approx0.8050\) and \(r_B\approx0.1950\).

Expected heads and tails

Multiply each experiment’s heads and tails by its responsibility for each coin. For experiment 1, the expected counts for A are \(H_A=0.4491\times5\approx2.25\) and \(T_A=0.4491\times5\approx2.25\). For B they are \(H_B=T_B=0.5509\times5\approx2.75\). Repeating this for all experiments gives:

M-step

$$\theta=\frac{\text{Expected heads}}{\text{Expected heads}+\text{Expected tails}}$$ $$\theta_A^{\text{new}}=\frac{21.2975}{21.2975+8.5722}\approx0.7130,\qquad \theta_B^{\text{new}}=\frac{11.7025}{11.7025+8.4278}\approx0.5813$$

Repeat the E-step and M-step using these updated values. After ten iterations:

$$\boxed{\theta_A\approx0.80,\qquad\theta_B\approx0.52}$$
