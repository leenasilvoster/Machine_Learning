Precision and Recall

Two metrics used to measure the performance of a retrieval system are precision and recall. Think of a search engine: it retrieves some pages, but only some of the pages that exist are truly relevant. Precision and recall each ask a different question about how well it did.

PrecisionHow many retrieved items are relevant?
RecallHow many relevant items are retrieved?

Precision

Precision is the fraction of relevant instances among the retrieved instances.

🤔Ask yourself: out of everything the system retrieved, how much was actually correct?

Precision is the number of correct instances retrieved divided by all retrieved instances. In the matrix, focus on the outlined Predicted Positive column: true positives and false positives.

Precision = True PositiveTrue Positive + False Positive

📌 Example
A search returns 10 pages and 8 of them are relevant. Precision = 8 ÷ 10 = 0.8, which is 80%.

Recall

Recall is the fraction of relevant instances that were retrieved.

🤔Ask yourself: out of everything that was actually correct, how much did the system find?

Recall is the number of correct instances retrieved divided by all correct instances. In the matrix, focus on the outlined Actual Positive row: true positives and false negatives.

📌 Example
There are 20 relevant pages in total and the search finds 8 of them. Recall = 8 ÷ 20 = 0.4, which is 40%.

Accuracy

Accuracy is the number of correctly classified data instances divided by the total number of data instances.

🤔Ask yourself: out of all the predictions made, how many were correct?

Correct predictions are the true positives (TP) and true negatives (TN). Every prediction, correct or not, is counted in the denominator.

Accuracy = TN + TPTN + FP + TP + FN
= Correct predictionsTotal predictions
📌 Example
A classifier makes 100 predictions and 90 of them are correct. Accuracy = 90 ÷ 100 = 0.9, which is 90%.
⚠️ Be careful
Accuracy may not be a good measure when the dataset is imbalanced, that is, when the negative and positive classes have different numbers of instances. For example, if 95 of 100 instances are negative, a model that always predicts "negative" scores 95% accuracy, yet it never finds a single positive.

F-Measure

The F1 score combines precision and recall into a single value, seeking a balance between the two.

🤔Ask yourself: how can I judge precision and recall together with just one number?

The F-score is a weighted average of precision and recall. The F1 score is their harmonic mean, so it is high only when both precision and recall are high.

F1 = 2 × Precision × RecallPrecision + Recall
📌 Example
Precision = 0.8 and Recall = 0.4. F1 = 2 × (0.8 × 0.4) ÷ (0.8 + 0.4) = 0.64 ÷ 1.2 ≈ 0.53. The simple average would be 0.6, so F1 is pulled down by the weaker score.
✅ When to use
F1 may be a better measure when we need a balance between precision and recall and the class distribution is uneven, that is, when there is a large number of actual negatives.

ROC curve and AUC

Rates from the confusion matrix

Sensitivity (True Positive Rate, TPR)

The fraction of correct predictions among all points in the positive class. It is simply the recall for the positive class.

TPR = recallP = TPTP + FN

Specificity (True Negative Rate, TNR)

The fraction of correct predictions among all points in the negative class. It is simply the recall for the negative class.

TNR = specificity = recallN = TNFP + TN

False Negative Rate (FNR)

The fraction of positive points that the classifier wrongly predicts as negative.

FNR = FNTP + FN = 1 − sensitivity

False Positive Rate (FPR)

The fraction of negative points that the classifier wrongly predicts as positive.

FPR = FPFP + TN = 1 − specificity

Receiver Operating Characteristic (ROC) curve

A ROC curve can only be used to assess classifiers that return a confidence score, or a probability, for their predictions.

📌 Examples
Logistic regression, neural networks and decision trees (and ensemble models based on decision trees) can all be assessed using ROC curves.

ROC curves commonly use the combination of the true positive rate (TPR) and the false positive rate (FPR), which are given as:

TPR = TPTP + FN  and  FPR = FPFP + TN

Area Under Curve (AUC)

The higher the area under the ROC curve (AUC), the better the classifier.

AUC > 0.5The classifier is better than a random classifier.
AUC < 0.5Something is wrong with your model.
AUC = 1A perfect classifier.
AUC valuesTest quality
0.9 – 1.0Excellent
0.8 – 0.9Very good
0.7 – 0.8Good
0.6 – 0.7Satisfactory
0.5 – 0.6Unsatisfactory

ROC curves are insensitive to class skew.

The TPR can be read as the probability of predicting a positive point as positive. The FPR can be read as the probability of predicting a negative point as positive. Neither depends on the ratio of the positive class size to the negative class size.

✅ Good to know
This is a desirable property. The ROC curve stays essentially the same whether the classes are balanced (about the same number of points) or skewed (one class has many more points than the other).

Bootstrapping and cross validation

Bootstrapping

The bootstrap method is a resampling technique used to estimate statistics on a population by sampling a dataset with replacement.

🤔Ask yourself: how can I estimate something about a population when I only have one dataset?

The bootstrap method estimates quantities about a population by averaging the estimates from multiple small data samples.

How it works

  1. Generate t samples of size n by sampling from the dataset D with replacement. The same point can be chosen more than once, so each sample Di is different.
  2. For each sample Di, run the same algorithm.
